# وتين ستي

**وتين ستي** لعبة عالم مفتوح ثلاثية الأبعاد، تُبنى للهاتف أولاً، وتكون اللغة العربية هي اللغة الأساسية في الواجهات والمهام والإعدادات وأسماء المناطق.

## الرؤية
- مدينة أصلية واسعة بأحياء ومناطق متنوعة.
- استكشاف حر من منظور الشخص الثالث.
- مشاة ومركبات وطرق ومبانٍ.
- منازل ومتاجر ووظائف ومهمات.
- نظام حياة داخل المدينة مع طقس وليل ونهار.
- تحكم باللمس وتحسين الأداء لمختلف الهواتف.

## التقنية
- JavaScript وThree.js للرسم ثلاثي الأبعاد.
- Vite للبناء.
- GitHub Pages للنشر.

## التشغيل محلياً
```bash
npm install
npm run dev
```

## البناء
```bash
npm run build
```

هذه نسخة تأسيسية قيد التطوير؛ ستضاف الأنظمة والمناطق على مراحل مع اختبار كل مرحلة.
