# SHADOW PROTOCOL

An expandable open-world life simulation, beginning with a small playable 3D frontier.

## Current foundation

- Vite-powered web application
- Three.js real-time 3D scene
- Procedural rolling terrain, river, trees, and first settlement buildings
- Orbit-style camera controls: drag to look, scroll to zoom
- Keyboard navigation with WASD or arrow keys
- Responsive desktop, mobile, and landscape layouts

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Development direction

The project is intended to grow in stages: world streaming and terrain tools, player movement and interaction, survival and inventory, NPC schedules, farming and trade, construction, quests, persistence, and eventually multiplayer services.

This repository is the active project. No deployment or production testing is implied by the source files alone.
